# 四足机器人控制逻辑文档

> 开发板: DM-MC-Board02 (CtrBoard-H7 V1.0)  
> MCU: STM32H723VGT6 @ 480MHz  
> 电机: 8× DM4310 关节电机 + 4× DM H6215 轮毂电机  
> 最后更新: 2026-06-28

---

## 1. 系统架构

```
┌─────────────────────────────────────────────────────────┐
│                    四足机器人板 (本板)                     │
│                                                         │
│  FDCAN1 (PD0/PD1) ──→ 8× DM4310 关节电机 (0x01-0x08)   │
│     · 1Mbps 经典CAN                                     │
│     · MIT模式 (位置+速度+力矩前馈)                         │
│                                                         │
│  FDCAN2 (PB5/PB6) ──→ 轮毂电机板                         │
│     · 1Mbps 经典CAN                                     │
│     · 发送: ID 0x100 运动指令                             │
│     · 接收: ID 0x101 SBUS遥控状态                         │
│                                                         │
│  SPI2 ──→ BMI088 IMU (加速度+陀螺仪)                      │
│  USART1 (PA9/PA10) ──→ 调试串口 (921600bps)              │
│  PC14 ──→ 电机电源使能                                    │
└─────────────────────────────────────────────────────────┘
         │                           │
         │ CAN2 (PB5/PB6)            │
         ▼                           ▼
┌─────────────────┐     ┌─────────────────────┐
│  轮毂电机板       │     │  SBUS 遥控接收机       │
│  (另一块DM-MC02)  │◄───│  (接在轮毂电机板上)      │
│                 │     └─────────────────────┘
│ FDCAN1 → 4×轮毂  │
│ (0x09-0x12)     │
└─────────────────┘
```

### 电机-腿部映射

| 腿 | 关节电机 (α/Beta) | CAN ID | LEG宏 | 轮毂电机 | CAN ID |
|----|-------------------|--------|--------|----------|--------|
| 左前 LF | Motor1(α), Motor2(β) | 0x01, 0x02 | LEG1 | 0x09 | |

## 2. 启动流程

```
上电 → SystemClock_Config (480MHz)
    → MX_GPIO_Init (PC14=低)
    → MX_FDCAN1_Init + MX_FDCAN2_Init
    → MX_SPI2_Init + MX_TIM3/4_Init + MX_USART1_UART_Init
    → power(1)           ← PC14拉高, 电机上电
    → HAL_Delay(1000)    ← 等1秒电源稳定
    → HAL_TIM_PWM_Start  ← TIM3 CH4 PWM启动
    → bsp_fdcan_set_baud ← FDCAN1/FDCAN2 设为1Mbps经典CAN
    → bsp_can_init       ← 启动FDCAN, 配置过滤器, 使能中断
    → dm_motor_init      ← 初始化8个电机数据结构
    → BMI088_Init        ← IMU初始化
    → 循环: clear_err(1..8) ← ★ 清除电机历史错误
    → 循环: enable_motor_mode(1..8, MIT_MODE) ← ★ 使能MIT控制
    → 主循环
```

### 缓启动 (startup_progress)

使能电机后，机器人进入 **~2秒缓启动**：

```
startup_progress: 0.0 → 1.0 (每次+0.0015 / 3ms ≈ 2s)

start_y = 90 → 身体从y=90缓慢下落到目标站立位姿
             → kp_ratio 从0→1 (刚度逐渐增强)
             → 期间无视SBUS遥控, 只做STAND
             → 防止上电瞬间电机猛转
```

## 3. 主循环 (3ms 控制周期)

```
while(1) {
    ┌─ 每4ms: IMU读取 + 互补滤波(俯仰/横滚)
    │
    ├─ 每50ms: CAN2发送运动指令到轮毂板 (ID 0x100)
    │         [float forward_rpm][float steer_norm]
    │
    └─ 每3ms (CTRL_PERIOD_MS): ====== 核心控制周期 ======
         │
         ├─ 1. SBUS遥控读取 (从CAN2接收)
         │     ch1=转向  ch3=油门  ch5=解锁
         │     alive = (now - can2_rx_tick) < 300ms
         │     armed = ch5 > 500
         │
         ├─ 2. 步态决策
         │     if (解锁 && alive && 启动完成) {
         │         if (|ch1| > 200) → TROT (缓入)
         │         else            → STAND (缓出)
         │         turn_progress: 0↔1 渐变 (375ms)
         │     } else {
         │         STAND (安全停止)
         │     }
         │
         ├─ 3. 步态生成 gaitMode(mode, freq, height, stride)
         │     STAND: 站立位姿 (X_ZERO=±62.5, y=start_y)
         │     TROT:  对角小跑步态
         │       height = 85 * turn_progress  (缓升抬腿)
         │       stride = 油门×25 * turn_progress
         │       turn_x = 转向×25×0.75 * turn_progress (不对称转弯)
         │
         ├─ 4. 足端位置平滑插值
         │     foot_pos = stand_pos + (gait_pos - stand_pos) × smooth_gait
         │
         ├─ 5. ★ TROT刚度增强
         │     trot_kp_scale    = 1.0 + 0.5 × turn_progress  (1.0→1.5)
         │     trot_extra_force = 10.0 × turn_progress        (0→10N)
         │
         ├─ 6. 每条腿 (LF→RF→RB→LB):
         │     ├─ 逆运动学 solveInverseKinematics(x,y) → α, β
         │     ├─ 足力估计 estimateFootForce() → 触地检测
         │     ├─ 雅可比力矩 calcJacobianAndTorque() → 前馈力矩
         │     └─ MIT控制 mit_ctrl(pos, vel, Kp, Kd, torque_ff)
         │         Kp = VMC_KP(40) × trot_kp_scale(1.0~1.5)
         │         torque_ff = 支撑力(0~10N) 或 体重补偿(1.2×)
         │
         └─ 7. Targeted_Safe_Damping (IK无解时安全阻尼)
}
```

## 4. 步态系统

### 4.1 步态模式

| 模式 | 枚举值 | 描述 | 频/高/幅定义 |
|------|:------:|------|:-----------:|
| STAND | 5 | 站立(默认) | freq=0, height=0, stride=0 |
| TROT | 1 | 对角小跑 | freq=0.0035, height=85, stride=25 |
| PACE | 2 | 同侧溜蹄 | freq=0.0060, height=30, stride=50 |
| BOUND | 4 | 跳跃 | freq=0.0075, height=40, stride=80 |

### 4.2 步态参数说明

| 参数 | 含义 | 当前TROT值 |
|------|------|:---------:|
| `TROT_FREQ` | 相位增量 (每3ms) | 0.0035 |
| 对应周期 | 完整步态周期 | ~1.03s |
| 摆动相时长 | (1-faai)×周期 | ~411ms |
| `TROT_HEIGHT` | 足端抬升量 (mm) | 85 |
| `TROT_STRIDE` | 步幅 (mm) | 25 |
| `faai` (gait.h) | 支撑相占空比 | 0.60 |

### 4.3 踏步转弯机制

当 `|CH1| > SBUS_DEADBAND(200)` 时，在 TROT 步态基础上叠加不对称偏移：

```
turn_x = (CH1 / 1000) × TROT_STRIDE × 0.75 × turn_progress

左腿 (LF, LB):  x += turn_x     ← 右转时左腿多往前迈
右腿 (RF, RB):  x -= turn_x     ← 右转时右腿往后收
```

配合 CAN2 发送给轮毂电机的 `steer_norm`，腿+轮同时产生转向力矩。

### 4.4 STAND↔TROT 平滑过渡

用 `turn_progress` (0.0~1.0) 控制：

```
打转向 → turn_progress += 0.008/3ms → ~375ms 到 1.0
回中   → turn_progress -= 0.008/3ms → ~375ms 到 0.0

所有TROT相关量乘 turn_progress:
  height  = 85 × turn_progress
  stride  = 25 × 油门 × turn_progress
  turn_x  = ... × turn_progress
  Kp增益  = 1.0 + 0.5 × turn_progress
  支撑力  = 10 × turn_progress
```

## 5. VMC 虚拟模型控制

### 5.1 控制架构

```
目标足端位置(x,y) 
    │
    ├─→ 逆运动学(IK) → 目标关节角(α,β)
    │        │
    │        ├─→ 位置环 Kp×(pos_target - pos_actual) 
    │        ├─→ 速度环 Kd×(0 - vel_actual)          ← 阻尼
    │        └─→ 前馈力矩 (雅可比矩阵计算)
    │
    └─→ MIT控制指令 → CAN总线 → DM4310电机
```

### 5.2 关键参数

| 参数 | 值 | 含义 |
|------|:--:|------|
| `VMC_KP` | 40 | 位置刚度 (Nm/rad) |
| `VMC_KD` | 2.0 | 阻尼系数 |
| `VMC_SUPPORT_FORCE` | 0 | 基础支撑力 (目前为0, TROT时动态叠加) |
| `TOUCHDOWN_FORCE_TH` | 15N | 触地检测阈值 |

### 5.3 触地检测

```
estimateFootForce() → 垂向力 Fy
  if Fy > 15N → 足端着地 → 施加体重支撑力 (1.2× VMC_SUPPORT_FORCE)
  if Fy ≤ 15N → 足端悬空 → 施加设定支撑力 (applied_force)
```

### 5.4 IK 安全机制

当 `solveInverseKinematics()` 返回 false (目标点超出工作空间) 时，调用 `Targeted_Safe_Damping()` 将该腿的两个电机置为零刚度阻尼模式 (Kp=0, Kd=2)，防止电机暴走。

## 6. CAN2 板间通信协议

### 6.1 物理层

| 项目 | 配置 |
|------|------|
| 接口 | FDCAN2 |
| 引脚 | PB5(RX) / PB6(TX) |
| 模式 | 经典CAN (CAN 2.0B) |
| 波特率 | 1 Mbps |
| 终端电阻 | 120Ω (两端各一) |

### 6.2 数据帧

**四足板 → 轮毂板 (CAN ID 0x100)**，每 50ms:

| 字节 | 内容 | 类型 |
|:----:|------|------|
| 0-3 | `forward_rpm` | float |
| 4-7 | `steer_norm` | float |

- `forward_rpm`: 目标前进速度 RPM，范围 ±60
- `steer_norm`: 归一化转向，范围 -1.0 ~ +1.0

**轮毂板 → 四足板 (CAN ID 0x101)**，每 10ms:

| 字节 | 内容 | 类型 |
|:----:|------|------|
| 0-1 | CH1 转向 | int16 (-1000~+1000) |
| 2-3 | CH3 油门 | int16 (-1000~+1000) |
| 4-5 | CH5 解锁/急停 | int16 (-1000~+1000) |
| 6-7 | CH6 模式切换 | int16 (-1000~+1000) |

### 6.3 遥控通道功能

| 通道 | 功能 | 低位 | 高位 |
|:----:|------|------|------|
| CH1 | 转向 | 左转 | 右转 |
| CH3 | 油门 | 后退 | 前进 |
| CH5 | 全局解锁 | 急停(全部电机停) | 解锁 |
| CH6 | 轮毂控制权 | 遥控直驱 | CAN2/树莓派 |

## 7. 调试串口输出

USART1 (PA9 TX), 921600bps, 每 500ms 输出:

```
SBUS ch1=200 ch3=300 ch5=1000 alive=1 armed=1 gait=1 fwd=18.0 str=0.20 t=12345
```

| 字段 | 含义 |
|------|------|
| `ch1/ch3/ch5` | SBUS通道原始值 (-1000~+1000) |
| `alive` | CAN2数据是否在300ms内有更新 |
| `armed` | CH5是否在解锁位置 |
| `gait` | 当前步态 (5=STAND, 1=TROT) |
| `fwd` | 发送给轮毂电机的目标转速 RPM |
| `str` | 发送给轮毂电机的转向归一化值 |
| `t` | 系统tick |

## 8. 参数调优指南

### 8.1 踏步太软/抬不起腿

增大 `trot_kp_scale` 和 `trot_extra_force`:

```c
// main.c 第 364-365 行
trot_kp_scale    = 1.0f + 0.5f * turn_progress;  // 改 0.5→0.8 更硬
trot_extra_force = 10.0f * turn_progress;          // 改 10→20 更多支撑
```

### 8.2 踏步太硬/抖动

减小上述值。

### 8.3 腿拖地

```c
// main.c 第 62-64 行
#define TROT_HEIGHT   85   // 增大 → 抬更高
#define TROT_STRIDE   25   // 减小 → 水平拖距更短

// gait.h 第 10 行
#define faai  0.60        // 增大 → 支撑相更长, 摆动相更从容
```

### 8.4 转弯太猛/太慢

```c
// main.c 第 57 行
#define SBUS_DEADBAND  200   // 减小→更灵敏; 增大→更钝

// main.c 第 340 行附近
0.75f                        // 转向幅度系数: 减小→转更慢
```

### 8.5 过渡太快/太慢

```c
// main.c 第 227 行
turn_progress += 0.008f;    // 增大→切换更快; 减小→更平滑
```

### 8.6 站立稳定性

```c
#define VMC_KP  40.0f       // 增大→更硬; 减小→更软
#define VMC_KD  2.0f        // 增大→更多阻尼; 减小→更弹
```
